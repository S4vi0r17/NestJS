Comandos Útiles para Nest.js

  • Instalar Nest.js CLI: 
    npm i -g @nestjs/cli
  • Crear un nuevo proyecto: 
    nest new nombre-del-proyecto
  • Iniciar el servidor de desarrollo: 
    npm run start:dev
  • Crear un nuevo módulo: 
    nest generate module nombre-del-modulo
  • Crear un nuevo controlador: 
    nest generate controller nombre-del-controlador
  • Crear un nuevo servicio: 
    nest generate service nombre-del-servicio
  • Crear un nuevo guard: 
    nest generate guard nombre-del-guard
  • Crear un nuevo interceptor: 
    nest generate interceptor nombre-del-interceptor
  • Crear un nuevo pipe: 
    nest generate pipe nombre-del-pipe
  • Crear un nuevo filter: 
    nest generate filter nombre-del-filter
  • Crear un nuevo decorator: 
    nest generate decorator nombre-del-decorator
